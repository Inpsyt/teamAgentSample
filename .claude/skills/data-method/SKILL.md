# 데이터 정리 방법론 (data-method)

## 작업 절차

1. `doc-conventions`, 이 스킬을 로드한다
2. 입력 소스(파일, 붙여넣은 표, 조사 결과)를 파악하고 각 소스를 문서 "출처" 섹션에 기록한다
3. Tidy Data 원칙으로 정규화한 마크다운 표를 만든다 — 행은 관측 단위 1개, 열은 변수 1개(한 셀에 두 값 금지), 단위 통일, 컬럼 정의 명시
4. 데이터 품질 4차원을 점검하고 미달 항목을 기록한다: **완전성**(빠진 값), **정확성**(원출처 대조), **일관성**(소스·단위 간 충돌), **유일성**(중복 행)
5. 합계·평균 등 집계값은 **Bash(awk 또는 python3 한 줄)로 계산해 검증**한 뒤 기입한다 — 암산 금지
6. `workspace/30-data/YYYY-MM-DD-<주제>.md`에 저장한다

## 규칙

- 차트·시각화를 요청받으면 `dataviz` 스킬을 로드해 따른다
- 소스 간 수치가 충돌하면 임의로 고르지 않고 두 값을 병기하며 `[소스 불일치]`로 표시한다
- 빠진 값은 빈칸이 아니라 `-`로 표기하고 사유를 각주로 남긴다
- front-matter: `agent: data`, `status: 초안`
