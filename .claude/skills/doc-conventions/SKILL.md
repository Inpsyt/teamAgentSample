# 문서 규약 (doc-conventions)

모든 산출물 마크다운 파일은 아래 규약을 따른다.

## 1. 명명 규칙

- 형식: `YYYY-MM-DD-<주제>.md` (예: `2026-07-21-경쟁사-요금제-비교.md`)
- 주제는 한국어 가능, 공백 대신 하이픈(`-`) 사용
- 동일 주제 파일이 이미 존재하면 덮어쓰지 않고 `-v2`, `-v3` 접미사로 새 버전 생성

## 2. 저장 위치

| 산출물 유형 | 폴더 |
|---|---|
| 리서치·벤치마킹 보고서 | `workspace/10-research/` |
| 기획서·제안서·요구사항서 초안 | `workspace/20-drafts/` |
| 취합 데이터·표 | `workspace/30-data/` |
| 회의 아젠다·회의록 | `workspace/40-meetings/` |
| 일정·WBS·태스크 보드 | `workspace/50-schedule/` |
| IA·화면 정의서·유저 플로우·웹 요구사항 | `workspace/60-web-planning/` |
| 주간보고·요약본 | `workspace/70-reports/` |
| QA 리포트·리뷰 노트 | `workspace/80-qa/` |
| 완료 프로젝트 보관 | `workspace/90-archive/` |

- `workspace/00-inbox/`는 임시 메모·미분류 자료 보관용 — **명명 규칙·front-matter 없이 저장 가능**(형식 검사 제외). 정식 산출물은 여기 두지 않으며, archive 작업자가 정리 요청 시 적절한 폴더로 분류한다

## 3. front-matter (모든 산출물 필수)

```yaml
---
title: <문서 제목>
agent: <업무 유형 (research/benchmark/draft/data/meeting/schedule/web-planning/report/archive/qa/review)>
status: 초안 | 검토중 | 확정
related:
  - <관련 문서 상대 경로 (없으면 빈 목록)>
---
```

- 선택 키: `mode: 간단` — research 간단 조사 노트에만 붙인다(research-method §0). PM은 이 키로 review 생략 등급을 판별한다

## 4. 출처 표기 (각주형)

- 본문에는 각주 번호만 남긴다. 예: `...레코드는 통합하지만 관계를 잃는 경우가 많다 [1].`
- 본문 문장 안에 파일 경로·URL을 직접 쓰지 않는다.
- 전체 경로·URL은 문서 말미 `## 출처` 섹션에 번호 목록으로만 표기한다:
  - 웹 자료: `[1] <제목> — <URL> (접속일: YYYY-MM-DD)`
  - 내부 자료: `[2] <제목> — workspace/10-research/2026-07-15-시장조사.md §a`
- 확인되지 않은 내용은 본문에 `[확인 필요]` 마커만 짧게 붙인다. 사유·후속 계획 등 긴 설명은 "미확인·추가 조사 필요" 섹션에 모은다.

## 5. 한국어 작성 원칙

- 개조식(불릿·표) 기본
- 약어 첫 등장 시 풀네임 병기

## 6. 가독성 규칙

산출물은 30초 훑어보기와 정독 모두를 견뎌야 한다.

- **요약 우선**: front-matter 바로 아래 `## 요약` 섹션을 둔다 — 결론·핵심 근거·다음 액션 3줄. 모든 산출물 공통.
- 불릿 1개 = 1문장, 최대 2문장. 길어지면 하위 불릿으로 쪼갠다.
- 괄호 중첩 금지 — 괄호 안 괄호를 쓰지 않고, 한 문장에 괄호는 1개까지. 부연이 길면 별도 문장으로 뺀다.
- 표 셀은 구절 단위 — 2문장 이상이 필요하면 표 대신 소제목+불릿을 쓴다. 재현 절차·상세 근거는 표 아래 본문에 둔다.
- **볼드는 섹션당 최대 2회** — 결론에만 쓴다.

## 7. 작업자 공통 규칙

PM이 범용 subagent에 업무 유형과 스킬을 지정해 위임한다. 작업자는 업무 유형과 무관하게 아래를 지킨다.

- 위임 프롬프트에 지정된 스킬을 **작업 시작 전에 Skill 도구로 로드**하고, 해당 스킬의 "작업 절차"를 따른다
- 쓰기는 `workspace/` 아래 지정 폴더에만 한다. 프로젝트 설정(`.claude/`, `CLAUDE.md`, `README.md`)은 수정하지 않는다
- 파일을 삭제하지 않는다 (archive도 이동만)
- 다른 subagent를 호출하지 않는다. 후속 작업이 필요하면 최종 응답에 제안만 남긴다 (PM이 다음 위임을 만든다)
- 검색 실패·자료 부족이어도 부분 결과를 저장하고, 남은 질문을 "미확인·추가 조사 필요 항목"에 기록한다
- 최종 응답에는 저장한 파일 경로와 3줄 요약을 반환한다
