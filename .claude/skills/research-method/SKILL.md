# 리서치 방법론 (research-method)

Malhotra 『Marketing Research』의 리서치 프로세스를 데스크 리서치에 맞게 적용한다.

## 1. 조사 프로세스 (Malhotra 6단계 적용)

| 단계 | 할 일 |
|---|---|
| ① 문제 정의 | 의뢰 배경(경영 문제)과 조사 질문(리서치 문제)을 구분해 문서 서두에 명시. 조사 질문을 하위 질문으로 분해 |
| ② 접근법 개발 | 하위 질문별로 "무엇이 확인되면 답이 되는가"(판단 기준·가설)를 정의 |
| ③ 조사 설계 | 조사 성격을 선언: **탐색적**(동향·가능성 파악) / **기술적**(시장 규모·현황 수치) / **인과적**(원인-결과 검증). 성격에 따라 요구되는 근거 강도가 다르다 — 기술적·인과적 주장에는 수치 출처가 필수 |
| ④ 자료 수집 | 2차 자료(기존 발간물) 우선 → 부족분만 추가 탐색. 아래 §2 평가 기준으로 자료를 선별 |
| ⑤ 분석·검증 | 핵심 주장은 독립된 출처 2개 이상으로 교차 검증(§3). 출처 간 불일치는 숨기지 말고 병기 |
| ⑥ 보고 | doc-templates "리서치 보고서" 템플릿. 결론은 조사 질문에 1:1 대응시킨다 |

## 2. 2차 자료 평가 기준 (Malhotra)

수집한 자료마다 아래를 점검하고, 미달 자료는 근거로 쓰지 않거나 한계를 명시한다.

- **방법론(사양)**: 어떻게 수집된 데이터인가 (표본, 조사 방식이 밝혀져 있는가)
- **정확성**: 원출처(1차 발표)까지 거슬러 확인했는가 — 재인용은 원출처로 교체
- **최신성**: 발행 시점이 조사 목적에 유효한가 (오래된 수치는 발행연도 병기)
- **목적**: 발행 주체의 이해관계(홍보·판촉 자료 여부)를 감안했는가
- **신뢰성**: 발행 주체의 전문성·평판

## 3. 출처 신뢰도 위계와 교차 검증

신뢰도 위계 (높음 → 낮음):

1. 정부·국제기구 통계, 학술 논문, 기업 공시(IR·사업보고서)
2. 조사기관·컨설팅펌 리포트 (Gartner, Statista 등)
3. 주요 언론 보도
4. 기업 블로그·보도자료 (이해관계 감안)
5. 커뮤니티·개인 블로그 (단독 근거 불가 — 참고 단서로만)

- **교차 검증 성립 조건**: 서로 다른 발행 주체의 독립된 출처 2개 이상. 같은 원출처를 재인용한 기사 2건은 출처 1개로 센다
- **독립성 판정은 원출처 기준**: 언론·리포트가 인용한 원천 데이터가 무엇인지 1단계만 소급해 확인한다. 서로 다른 기관이라도 같은 원천 데이터(동일 정부 통계·동일 조사)를 가공했다면 독립 출처가 아니다. 원출처가 밝혀져 있지 않으면 독립성을 인정하지 않는다
- 위계 4~5만으로 뒷받침되는 주장은 **미확인**으로 표기한다
- 수치는 기준 시점·범위(국가, 세그먼트)를 함께 기록한다 — 시점·범위가 다른 수치의 비교 금지

## 흔한 실수

- 조사 질문 없이 검색부터 시작 → 결과가 나열형이 됨. 반드시 ①②를 문서에 먼저 쓴다
- 재인용 기사를 독립 출처로 계산해 "교차 검증됨" 처리
- 탐색적 조사 결과를 기술적 결론("시장 규모는 X다")처럼 단정
